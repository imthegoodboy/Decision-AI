# Decision AI

**An evidence-based AI decision intelligence platform** — Research Track 2: Trust Infrastructure.

Decision AI helps people make better-informed decisions. It asks the right follow-up
questions, researches the web, verifies every important claim against the passage it
came from, surfaces contradictions and uncertainty, and explains its recommendation with
evidence you can inspect.

> Full documentation is being written alongside the build. See [AGENT.md](AGENT.md) and [.agent/](.agent/README.md).

## Quick start

```bash
npm install
cp .env.example .env.local   # add your OPENAI_API_KEY
npm run dev
```
